Roadmap: beginner to professional

Timelines assume steady study of 10 to 15 hours a week. Move faster or slower as your life allows.

  1. Months 1 to 2

    Learn the foundations

    How computers, operating systems and the internet work. Get comfortable with Windows and Linux, the command line, basic networking (IP, DNS, HTTP) and typing and troubleshooting skills.

  2. Months 3 to 5

    Learn to code and use Git

    Start with Python or JavaScript. Learn variables, loops, functions, data structures and reading documentation. Use Git and GitHub from day one and write small scripts that solve real problems.

  3. Months 5 to 7

    Add databases and web basics

    Learn SQL, one NoSQL database, HTML, CSS and how APIs work. Build a small app that stores and shows data.

  4. Months 7 to 12

    Choose a specialization

    Pick one domain from the list above: web development, cloud and DevOps, cybersecurity, data and AI, or networking. Go deep in one before widening.

  5. Months 12 to 18

    Build a portfolio and earn certifications

    Ship three to five real projects, write about what you learned and publish them on GitHub. Add a recognized certification such as CompTIA Security+, AWS Cloud Practitioner or Google Data Analytics.

  6. Month 18 onward

    Work, freelance and keep growing

    Apply for junior roles, internships or freelance work. Keep learning: read release notes, join communities, contribute to open source and mentor beginners.

The future of IT

Trends that are already changing which skills are valuable.

Artificial intelligence

AI assistants and agents are becoming part of everyday development, support and analysis. Skills in prompting, evaluating models and building AI-powered apps are in demand.

Cloud and edge computing

More systems run on cloud platforms and close to users on edge devices. Cloud architecture, cost control and serverless design keep growing.

Cybersecurity everywhere

Attacks are increasing, and security is now part of every role. Zero trust, identity management and secure coding are core skills.

Automation and platform engineering

Teams automate infrastructure, testing and deployment. Infrastructure as code, CI/CD and Kubernetes remain strong career paths.

IoT and smart systems

Billions of connected devices need embedded programming, networking and security expertise.

Quantum and blockchain

Still emerging. Quantum computing will change cryptography, and blockchain supports digital identity and finance. Learn the basics and watch closely.

How to use this guide

  • Learn by building. Every topic should end with something you made.
  • Master one skill before starting the next. Breadth comes after depth.
  • Practice in safe, legal labs. For security, use platforms like TryHackMe, Hack The Box and your own virtual machines, and only test systems you own or have written permission to test.
  • Keep a public record: GitHub projects, a blog or a LinkedIn profile that shows your progress.
  • Learn English and communication. Clear writing and teamwork matter as much as technical ability.
  • Review the roadmap every six months, because tools change quickly.
